`data-init` fetches once on load and `data-on-interval__duration.5s`
re-fetches every five seconds. The endpoint renders the same
`<ServerTime/>` component the page used for its loading state; the morph
swaps it in place.

```html
<div data-on:refetch="@get('/api/time')">
  <button data-on:click="evt.target.dispatchEvent(new CustomEvent('refetch', {bubbles: true}))">
    Refresh now
  </button>
</div>
```
